# Nexa

واجهة ويب تجريبية لـ **Nexa** بهوية مستقبلية، شاشة بداية، تسجيل دخول بسيط، واجهة شات، ووضع أكواد ذكي (Split View) مع Workflow واضح لتحويل المشاريع إلى APK.

## التشغيل

```bash
python3 -m http.server 4173
```

ثم افتح: `http://localhost:4173`

## الميزات

- Splash Screen مع Typewriter + Glow + Particles.
- Login بحقل اسم واحد فقط.
- Chat UI بأسلوب Dark Glassmorphism.
- Typing Indicator وحركات انتقال سلسة.
- Smart Code Mode (Copy / Download / Run).
- Workflow عملي لتحويل التطبيقات إلى APK والنشر على Google Play.
